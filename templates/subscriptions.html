User Subscriptions

              GET /api/subscriptions/user-subscriptions/ - List
              subscriptions

  •

                /api/subscriptions/user-subscriptions/status/?user_id={id}
              - Get status
            
    • 
            
  • 
              POST
                /api/subscriptions/user-subscriptions/create_or_link/
              - Create/link

  • 
              POST /api/subscriptions/user-subscriptions/sync/ -
              Sync from RevenueCat

  • 
              POST /api/subscriptions/grant-promotional/ - Grant
              promo access
            
    • 
            
  • 
              POST /api/subscriptions/revoke-promotional/ - Revoke
              promo access
            
    • 
            
  • 
              GET
                /api/subscriptions/check-feature/?user_id={id}&feature={name}
              - Check feature
